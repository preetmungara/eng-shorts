# Eng Shorts

Scroll through recent posts from engineering blogs, one card at a time.

Each card shows the company, title, a short excerpt, and a link to the full post. Read posts are remembered in your browser (`localStorage`). Nothing is stored on a server.

**Keys:** `j` / `↓` / `PageDown` = next, `k` / `↑` / `PageUp` = previous, `Enter` = open.

## How an article gets picked

A script (`scripts/collect.ts`) runs every 6 hours and builds `public/articles.json`. For each source in `feeds.json`:

1. **Fetch the RSS feed.** (Anthropic has no feed, so its page is read directly.)
2. **Filter out non-engineering posts.**
   - Posts with obvious non-post titles (webinars, case studies, press releases, hiring, acquisitions) are always dropped.
   - Sources are split into two kinds:
     - *Dedicated engineering blogs* (e.g. Netflix): trusted, only dropped if they look like marketing.
     - *Mixed company blogs* (e.g. Stripe, Cloudflare): must have a technical title and a good score to get in.
   - The score goes up for technical words in the title (latency, Postgres, "how we built…"), code blocks in the post, long posts, and engineering categories. It goes down for marketing words (announcing, pricing, customers…), "how to / top 10" style titles, and short posts.
3. **Remove duplicates** by URL.
4. **Rank.** Posts that did well on Hacker News (20+ points) come first, then newest first. At most 12 posts per company, so no one dominates.
5. **Write an excerpt** from the feed. If missing, it is taken from the page's meta description. Excerpts that repeat across many posts are removed.

The filter is deliberately strict: missing a good post is cheaper than showing a marketing one.

## Technical details

- **Frontend:** Preact + Vite + TypeScript (`src/`). Static site, no backend.
- **Data:** `public/articles.json`, generated by `npm run collect`. Uses `rss-parser`.
- **Sources:** add or remove blogs in `feeds.json` (`{ "company": "...", "url": "..." }`). If a company posts a lot of marketing, add its name to the `MIXED` list in `scripts/collect.ts`.
- **Deploy:** GitHub Actions (`.github/workflows/update.yml`) collects, builds, and publishes to GitHub Pages on push to `main`, every 6 hours, or manually.
- **Requires:** Node 26 or newer.

## Run locally

```bash
npm install
npm run collect   # fetch posts into public/articles.json
npm run dev       # start the app
```

Other commands: `npm run build` (type-check and production build), `npx tsx scripts/collect.ts --check` (self-check of the ranking logic).
